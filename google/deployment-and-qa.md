# نصب، آزمون و انتشار

## ترتیب تحویل

1. رسول کانتینر GTM-WSNCPQCX را یک‌بار نصب و fx_page_ready و fx_form_success را طبق [قرارداد](measurement-contract.md) پیاده می‌کند.
2. در محیط کنترل‌شده، Preview/DebugView و سناریوهای جدول زیر اجرا و نتیجه ثبت می‌شود.
3. پس از قبولی، نسخهٔ GTM با نام FXE foundation و شرح تغییرات منتشر می‌شود.
4. دریافت عادی GA4 و اولین جدول روزانهٔ BigQuery مستقلاً تأیید می‌شود.

پنج تگ در نسخهٔ ۲ ذخیره شده‌اند؛ نسخهٔ Live همچنان Empty Container است. آزمون‌های آفلاین 185 مورد موفق‌اند؛ فایل Import با خروجی بومی نسخهٔ ۲ تطبیق داده شده است. این شواهد، آزمون زنده یا دریافت داده نیستند.

| سناریو | معیار قبولی | وضعیت |
|---|---|---|
| ورود اولیه | دقیقاً یک page_view، عنوان/URL صحیح | منتظر نصب |
| SPA و Back/Forward | هر نمایش واقعی یک بازدید؛ عنوان و referrer تازه | منتظر پیام برنامه |
| رندر/مودال/hash | بازدید اضافی صفر | اجرا نشده |
| تماس | روش صحیح؛ بدون تلفن/ایمیل خام | اجرا نشده |
| خروج به زیرسیستم | consultant/iran/digital/trade و جایگاه صحیح | اجرا نشده |
| فرم خطا/timeout | generate_lead صفر | منتظر hook و محیط کنترل‌شده |
| فرم پذیرفته‌شده | generate_lead یک؛ form_id مجاز، بدون فیلدها | منتظر hook و محیط کنترل‌شده |
| مرورگر تیم / عادی | traffic_type فقط برای تیم؛ فیلتر Testing | اجرا نشده |
| دادهٔ ارسالی | بدون فرم، توکن، query آزاد و raw contact URL | اجرا نشده |
| بعد از انتشار | دریافت عادی در GA4، بدون تکرار | منتشر نشده |
| BigQuery Daily | جدول events_YYYYMMDD و شمار رویداد معتبر | تأیید نشده |

فرم واقعی برای ایجاد دادهٔ تست ارسال نشده است. برای QA موفق/ناموفق از محیط آزمون یا ارسال آزمایشی هماهنگ‌شده استفاده شود. اگر تگ‌های پایه یا کانتینر دیگری روی سایت وجود داشت، قبل از انتشار موجودی و مسیر تکراری بررسی شود. توکن Preview در مخزن ذخیره نشود.
