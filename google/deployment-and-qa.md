# نصب، آزمون و انتشار — اکوسیستم

این چک‌لیست برای مرحلهٔ آینده است؛ هیچ مورد نصب/تست زنده‌ای با این سند تأیید نمی‌شود.

1. موجودی صفحات، زبان‌ها، Router، فرم‌ها و روش رضایت کاربر بررسی و قرارداد اندازه‌گیری نهایی شود.
2. کد GTM-WSNCPQCX مطابق دستور نصب خود کانتینر یک‌بار در قالب عمومی سایت نصب شود. اسکریپت مستقیم GA4 موازی اضافه نشود. این کار در مخزن برنامه فقط توسط مسئول سایت انجام شود.
3. روش page_view خودکار یا دستی با توجه به Router انتخاب شود. اگر دستی بود، پیام صفحه از برنامه پس از عنوان نهایی فرستاده شود.
4. پیام فرم موفق به پاسخ واقعی Backend متصل شود. کلیک Submit و نمایش خطا سرنخ موفق نیست.
5. در Preview/DebugView جدول زیر تکمیل شود. انتشار GTM پس از قبولی آزمون‌ها باشد.
6. پس از انتشار، دریافت عادی GA4 و اولین جدول روزانهٔ BigQuery تأیید شود.

| سناریو | انتظار | وضعیت فعلی |
|---|---|---|
| ورود اولیه | یک page_view با URL/عنوان صحیح | اجرا نشده |
| تغییر مسیر، برگشت و جلو | هر نمایش واقعی یک بازدید، بدون تکرار رندر | اجرا نشده |
| تغییر زبان | زبان محتوا و مسیر صحیح | اجرا نشده |
| تماس/خروج به زیرسیستم | فقط مقصد مجاز، بدون دادهٔ تماس خام | اجرا نشده |
| فرم ناموفق | صفر رویداد موفقیت | اجرا نشده |
| فرم پذیرفته‌شده | یک موفقیت، بدون دادهٔ شخصی | اجرا نشده |
| رویدادهای خودکار بعد از تغییر مسیر | URL صحیح، بدون دادهٔ حساس | اجرا نشده |
| مرورگر تیم / عادی | تفکیک درست قبل از فعال‌سازی حذف | اجرا نشده |
| دریافت BigQuery | جدول روزانه و شمار رویداد معتبر | اجرا نشده |

از توکن Preview، رمز، کلید و دادهٔ واقعی فرم در گزارش یا مخزن استفاده نشود. خروجی GTM پس از ذخیرهٔ واقعی گرفته شود؛ فایل Import تولیدشده به‌عنوان پشتیبان بومی معرفی نشود.
